# Gemini 全景图 UI 优化实施计划

## 目标

将现有页面从渐变玻璃卡片风格调整为「编辑杂志型时间线」与 Material 风格控件的组合：以米白/深墨色建立阅读底色，蓝色作为单一强调色，强化年份轴、事件层级与筛选工具栏，同时保留所有现有数据、交互和自动更新逻辑。

## 涉及文件

- `work/build-page.py`：调整内联 CSS，必要时微调页面语义 class，不改时间线数据和自动更新代码。
- `tests/test_gemini_evolution_panorama.py`：增加视觉系统、年份轴、响应式和离线资源的静态回归测试。
- `README.md`：同步更新 UI 特征和页面使用说明。
- `outputs/gemini-evolution-panorama.html`：由构建器重新生成，不直接维护。

## 实现步骤

1. 先增加新版视觉契约测试，验证编辑型颜色变量、扁平卡片、年份轴和移动端结构，并确认旧的紫蓝渐变实现不再出现。
2. 重写构建器内联 CSS 的颜色变量、页面背景、首屏、统计卡、筛选工具栏、年份组、事件卡片和归档卡片样式。
3. 保留并优化 Material 风格输入框、下拉框、复选框、按钮的焦点与悬停反馈；补齐窄屏单列时间线和横向可滚动筛选导航。
4. 重新生成单文件 HTML，运行 Python 测试、语法检查、JSON 校验和 `git diff --check`。
5. 在浏览器中检查桌面、平板和手机宽度的层级、溢出、筛选、主题和打印表现。

## 关键设计决策

- 不引入字体、CSS 框架或运行时依赖，保证单文件离线阅读。
- 不修改事件数据、来源、自动更新脚本和 URL 状态协议。
- 使用高对比米白/深墨色作为基础色，蓝色作为主交互色；类别色仅保留在小型标签上。
- 通过年份左栏与连续轨道建立明确的时间阅读路径；移动端改为年份标题后紧接事件列表。
- 减少圆角、透明度和阴影层级，避免装饰抢过内容；保留主题切换、减少动画和打印样式。
